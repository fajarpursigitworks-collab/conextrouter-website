FAQ

Jawaban singkat tentang model, pembayaran, routing, dan integrasi.

Apa itu ConextRouter?

Gateway API yang menghubungkan aplikasimu ke berbagai model AI lewat satu API key.

Model AI apa yang tersedia?

Tersedia berbagai model dari OpenAI, Google Gemini, Anthropic Claude, Alibaba Qwen, DeepSeek, dan provider lainnya. Daftar model akan terus diperbarui.

Bagaimana ConextRouter memilih model AI?

Sistem menilai kompleksitas setiap request lalu mengarahkannya ke model yang sesuai. Tugas sederhana menggunakan model yang lebih ringan, sedangkan tugas kompleks diarahkan ke model dengan kemampuan reasoning lebih tinggi.

Bagaimana cara bayar?

Personal dapat top up melalui QRIS, VA, atau e-wallet. Untuk Enterprise tersedia skema tagihan bulanan.

Apakah perlu banyak perubahan kode?

ConextRouter kompatibel dengan format OpenAI dan Anthropic. Pada banyak kasus, cukup ganti base URL.

Siap mulai dengan ConextRouter?

Buat akun gratis. Saat kebutuhan tim berkembang, beralih ke Enterprise kapan saja.
